# 데이터·리소스 공개 검토

실행에 필요한 데이터와 이미지 원본은 변경하거나 삭제하지 않았습니다. 현재는 권한 검토 전 GitHub 포함을 보류합니다. `.gitignore`는 Git 업로드만 제어하며, 웹 서비스가 `public` 파일을 제공하는 것을 차단하지 않습니다.

| 경로 | 용량·내용 | 실행 역할 | 공개 전 확인 |
|---|---|---|---|
| `backend/data/programs_v1.json` | 66,361바이트, 프로그램 17개 | 목록·상세·전략 근거 | 검색·RACOI·유튜브 가공 데이터 재배포 조건 |
| `backend/data/videos_v1.json` | 300,016바이트, 후보 303개 | 영상·전략 제목 단서 | 제목·URL·채널 등 메타데이터 이용 조건과 개인 식별 가능 정보 |
| `backend/data/episodes_v1.json` | 10,568바이트, 회차 20개 | 회차 API | 방송일·출처 재배포 조건 |
| `backend/data/provenance_v1.json` | 1,962바이트 | 출처 API | 원본 CSV 부재, 기록된 사람 확인 이력의 공개 범위 |
| `backend/data/field_dictionary_v1.json` | 1,186바이트 | 분석 기준 문서 | 데이터 패키지와 함께 제공할지 결정 |
| `frontend/public/programs` | ID명·한글명 포스터 | 프로그램 이미지 | 방송사·제작사 이미지의 공개·재배포 권한 |
| `frontend/public/fonts` | Pretendard OTF 5개 | 현재 글꼴 | 실제 배포본 라이선스와 고지문 확보 |
| `frontend/public/brand` | 브랜드 이미지 | 공개 정적 리소스 | 로고 사용 권한 |
| `frontend/src/assets/hero.png` | 현재 앱에서 참조되지 않는 이미지 | 보관 자산 | 제작·입수 경위와 재배포 권한 |

JSON 합계는 380,093바이트로 파일 용량은 작지만, 용량이 작다는 이유만으로 공개할 수 있다고 판단하지 않습니다. 대표적인 키 패턴 검사에서는 코드 내 실제 키가 발견되지 않았으며 `.env`만 검출됐습니다. 이는 모든 개인정보·저작권·비밀 패턴에 대한 완전한 감사를 의미하지 않습니다.

새 환경에서 현재 화면을 재현하려면 위 파일을 기존 경로에 제공해야 합니다. 공개 권한을 확인한 항목만 `.gitignore`의 해당 제외 규칙에서 해제하고, 라이선스·출처 고지를 함께 추가하세요. 이 작업에서는 승인되지 않은 데이터 대체, 익명화, 수치 변경, 포스터 교체를 수행하지 않았습니다.
